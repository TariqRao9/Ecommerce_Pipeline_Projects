# 🗄️ PostgreSQL Data Transformation & Modeling

This directory contains the core database scripts used to clean, structure, and model raw e-commerce transactional data before it is visualized in Power BI. 

The primary objective of these scripts is to take raw sales tables and build an **RFM (Recency, Frequency, Monetary) Segmentation Matrix** to track customer behavior and calculate total financial revenue losses.

---

## 🛠️ SQL Processing Steps & Pipeline Logic

The scripts are written for **PostgreSQL** and follow a structured data transformation pipeline:

* **Data Cleaning & Type Casting:** Standardizing raw text dates into proper timestamps and filtering out incomplete records or zero-value transactions to ensure data integrity.
* **Customer Metrics Aggregation:** Grouping data by unique user IDs to calculate individual operational metrics:
  * **Recency:** Days since the customer's last purchase.
  * **Frequency:** Total number of distinct orders placed.
  * **Monetary Value:** Total historical revenue generated by the user.
* **RFM Score Assignment:** Utilizing NTILE or conditional logical functions to score users on a scale and segment them into distinct tiers (e.g., *Champions*, *Fading Customers*, *Loyal Customers*, *Churned Users*).
* **Cohort Churn Identification:** Aggregating monthly user activity to flag inactive accounts and isolate the exact historical revenue tied to users who stopped buying.

---

## 📁 Key Queries Stored Here

* `01_data_cleaning.sql` — Ingestion scripts, handling missing values, and database schema setup.
* `02_rfm_segmentation.sql` — Query logic calculating the behavioral metrics and assigning customer segments.
* `03_revenue_leakage_cohorts.sql` — Monthly grouping queries tracking the November churn spike and total revenue risk.
